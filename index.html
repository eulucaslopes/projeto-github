03 / Sem mistério

Perguntas que aparecem
no primeiro projeto.

Git e GitHub são a mesma coisa?+

Não. Git é o sistema de controle de versão que roda no seu computador. GitHub é a plataforma online que hospeda repositórios Git e facilita a colaboração.

Preciso saber programar para usar o GitHub?+

Não. Você pode explorar projetos, abrir issues, colaborar com documentação e aprender no seu ritmo. Programar é apenas uma das possibilidades.

O que significa fazer merge?+

É incorporar as alterações de uma branch em outra, normalmente levando uma funcionalidade revisada para a branch principal.
